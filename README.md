# XV da Lulu — V2

Convite digital responsivo para GitHub Pages.

## Arquivos
- `index.html` — estrutura do convite
- `style.css` — visual e responsividade
- `script.js` — navegação, contador, WhatsApp, Pix, compartilhamento e som do mar

## Publicação
Envie os três arquivos para a raiz do repositório e ative GitHub Pages em `Settings > Pages > Deploy from a branch > main > /(root)`.

## Configurações no JavaScript
No objeto `CONFIG` de `script.js`:
- `eventDate`: data/horário do evento
- `whatsappNumber`: WhatsApp de confirmação
- `pixKey`: chave Pix
- `address`: endereço final da festa
